Hi-Lo Card Counting

The Hi-Lo system assigns a value to every card. As cards are dealt, you keep a running count. A positive count means more low cards have left the deck — the remaining shoe favors the player.

CardsValueWhy
2, 3, 4, 5, 6+1Low cards help the dealer
7, 8, 90Neutral
10, J, Q, K, A−1High cards help you

Running Count → True Count

Divide the running count by the number of decks remaining in the shoe. This true count is what actually matters for betting and strategy.

Example: Running count is +6 with 3 decks left → True count = +6 ÷ 3 = +2.0

Basic Strategy Tips

  • Always stand on hard 17+
  • Always split Aces and 8s; never split 10s. One split only — Aces get one card each.
  • Double on 11 vs dealer 2–10
  • Never take insurance (it's a sucker bet even when counting)
  • At true count +2 or higher, consider increasing your bet
